section: Upgrade notes
---

- `DebugSessionTemplate` and `DebugSession` have the new optional field
  `spec.toolbox` (`image`, `mountPath`). Apply the CRDs before the controller.
  The digest-pinned image is mounted read-only as a Kubernetes image volume
  (KEP 4639, GA in Kubernetes 1.36) at `mountPath` (default
  `/opt/breakglass/toolbox`) into workload containers, the node debug container
  and the pod-copy debugger, and `BREAKGLASS_TOOLBOX` names the path. On target
  clusters without the ImageVolume API the API server drops the volume, and the
  session starts without the toolbox. Restricted catalogue profiles reject
  `spec.toolbox` (#1505).
